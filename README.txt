SAMUEL CHARO KAHINDI - PORTFOLIO WEBSITE

HOW TO VIEW
Unzip the folder and double-click index.html. It opens in your browser. No internet needed.

FILES
index.html, about.html, skills.html, projects.html, cv.html, contact.html  - the six pages
style.css                  - all colours, fonts and layout (the colours are at the top of the file)
images/                    - the 7 pictures (SVG). Replace them with your own photos and keep the same file names,
                             or change the file names inside the HTML files.

PRINTING THE CV
Open cv.html, click "Download / Print CV (PDF)", and choose "Save as PDF". It prints as two A4 pages.

PUTTING IT ONLINE
Upload the whole folder to any web host (for example Netlify, GitHub Pages or a Kenyan hosting company).

EDITING
Open any .html file in Notepad or VS Code and change the text. Sample details (jobs, schools, projects, prices,
client names) should be replaced with your real information.
